# 虚拟断路器模拟器（从站实训设备）

配套上位机软件：`低压塑壳断路器远程控制软件`（本仓库 `main.py`）。

本软件在电脑上模拟一台 **DL/T 645 带漏电保护、带自动重合闸的塑壳断路器**，
通过串口（建议使用 com0com 虚拟串口对）与上位机互通，使学生在没有真实
断路器的情况下完成"接线 — 通信 — 读数 — 遥控 — 整定 — 故障分析"的
完整实训，并能直接观察协议报文如何构成、校验和如何计算。

---

## 一、两个软件的角色

| 软件 | 角色 | 入口 |
| --- | --- | --- |
| 低压塑壳断路器远程控制软件 | 主站（上位机，监控中心） | `main.py` / `dist\低压塑壳断路器远程控制软件.exe` |
| 虚拟断路器模拟器 | 从站（断路器设备本体） | `virtual_main.py` / `dist\虚拟断路器模拟器.exe` |

两者使用**同一套协议实现**（`dl645_breaker/protocol.py`），因此报文逐字节
一致；虚拟设备侧在 `dl645_breaker/simulator.py` 的应答逻辑之上增加了电气量
仿真、保护逻辑与故障注入。

## 二、功能

### 1. 通讯设置（左侧栏）
- 端口号（自动枚举本机串口，支持刷新）
- 波特率 1200–38400（默认 9600）
- 数据位 8/7/6/5、校验 偶/奇/无、停止位 1/2（默认 **8E1**，与规约一致）
- 从站地址（默认 000000000001，可改，写参数 04000401 也会改地址）
- 开始监听 / 停止、运行状态灯、收帧/应答/校验错/丢帧统计

### 2. 综合实训台（复刻参考界面三大功能区）
- **系统参数测量**：选择设备 + 选择参数（70 条 DI 目录）→ 生成指令 →
  指令框可手工修改 → 发送 → 回显 HEX → 中文解析
- **系统设备控制**：选择设备 + 选择控制动作或写参数 + 设定频率（仿真电网
  50/60Hz）+ 预约延迟（NN/分钟/小时）→ 生成 → 发送 → 回显 → 解析
- **模拟测试系统**：启动测试/结束测试（自动循环读实时量）、指令源码
  （逐字段分解）、访问对象、读写操作、CRC 校验（CS 与应为值对照）、
  指令解析、随机行为（数值抖动/随机跳闸/混合，可设概率与间隔）

### 3. 实时监测
- 三相电压、三相电流、剩余电流、额定剩余电流、极限不驱动时间
- 运行状态字 1/2（十六进制 + 中文原因），合闸/分闸大色块指示
- 三相电流正弦波形 + 剩余电流进度条（相对额定值）
- 就地操作：合闸 / 分闸 / 试跳 / 自检（模拟按键操作）
- 故障注入：剩余电流（可填 mA）、过载、短路、缺相（选相）、过压、欠压、停电
- 工况参数：负荷率、保护时间加速（1–60 倍）、保护逻辑总开关、设备运行、
  重合闸延时

### 4. 通信日志
- 报文表格：时间 / 方向（RX 主站请求、TX 从站应答、事件）/ 地址 / 控制码 /
  L / 整帧 HEX / 说明
- 选中报文后：**帧结构分解**（起始符、地址域、数据区起始符、控制码、
  长度、数据域、CS、结束符）+ **校验和逐字节累加过程**

### 5. 协议教学
- 帧格式、字节格式（8E1）、控制码、异常信息字、读数据示例、数值量与
  分量型的字节序区别
- 控制字 1–5 / 状态字 1–2 位表（逐位含义与取值）
- 数据标识（DI）目录：名称、DI、长度、读/写/控制、编码说明

## 四、与上位机联调（推荐课堂流程）

1. 安装 **com0com**（或其它虚拟串口对工具），建立一对串口，例如
   `COM4 <-> COM5`；
2. 启动**虚拟断路器模拟器**：端口选 `COM5`，8E1/9600，
   从站地址 `000000000001`，点击 **开始监听**；
3. 启动**上位机软件**：通信模式选"串口"，端口选 `COM4`，点击 **连接设备**；
4. 上位机"实时监测"应显示三相电压约 220V、电流按负荷率、剩余电流约 20mA；
5. 上位机点"远程分闸/合闸"，虚拟设备闸位与状态字随之变化；
6. 在虚拟设备"实时监测"页注入**剩余电流 500mA**，约 0.1s（100ms 不驱动
   时间）后保护跳闸，原因"剩余电流"，上位机随轮询看到分闸与告警；
7. 上位机读取"保护动作记录""闸位变化记录"，与虚拟设备事件一致；
8. 若控制字 1 的"重合闸"位为允许（默认 0x64 → bit1=0），漏电跳闸 8 秒后
   自动重合闸一次；重合后漏电仍存在则再次跳闸。

### 没有虚拟串口怎么办？
在"调试主站链路"中选择 **内置回环**：指令不经过串口，直接交给本机虚拟
设备处理。学生仍可完成组帧、发送、回显、解析、帧分解、校验和计算的完整
实验，只是不涉及物理层。

## 五、建议的课堂实验

| 实验 | 操作 | 观察点 |
| --- | --- | --- |
| 1. 读实时量 | 参数测量 → 三相电压/电流/剩余电流 → 生成/发送 | 91H 应答、DI 回传、BCD 低字节在前、0.1V/0.01A |
| 2. 远程控制 | 设备控制 → 远程跳闸/合闸 → 发送 | 1CH 数据域 = DI+pwd+操作者(+NN/单位)，应答 9CH |
| 3. 参数整定 | 设备控制 → 写 "Ir1 过载动作电流" → 设定值 HEX | 14H 组帧、BCD 编码、写后读回校验 |
| 4. 漏电保护 | 实时监测 → 注入剩余电流 500mA | 状态字 1 原因 02H、跳闸次数、保护动作事件 |
| 5. 自动重合闸 | 控制字 1 置 0x66/0x64 对比，注入漏电 | bit1=0 允许 → 延时重合；bit1=1 禁止 |
| 6. 通信异常 | 指令框手工改 CS / 改地址 / 开随机丢帧 | 设备不应答或回异常应答，上位机超时/校验失败 |

### 手工改帧示例
正常读三相电压（地址 000000000001）：
```
68 01 00 00 00 00 00 68 11 04 33 32 34 35 B4 16
```
- 把最后第二个字节 `B4` 改成 `B5` → 校验和错误，虚拟设备**丢弃不应答**，
  日志"校验错 +1"；
- 把地址 `01 00 00 00 00 00` 改成 `02 00 ...` → 地址不符**不应答**；
- 把控制码 `11` 改成 `14` 但数据域不足 → 设备回 `D4H 01H`（数据非法）。

## 六、协议要点速查

```
帧：68H | A0-A5 | 68H | C | L | DATA | CS | 16H
DATA：DI0 DI1 DI2 DI3 | 密码(4) | 操作者(4) | 数据
传输：数据域每字节 +33H；接收 -33H
CS ：从第一个 68H 到 CS 前一字节求和 mod 256
地址：6 字节 BCD，低字节在前；999999999999 广播；AA 缩位
控制码：D7 方向 / D6 应答 / D5 后续 / D4-D0 功能
    11H 读  91H 读应答  D1H 读异常
    14H 写  94H 写应答  D4H 写异常
    1CH 控制 9CH 应答   DCH 异常
    1BH 清零 9BH 应答   DBH 异常
    18H 改密 98H 应答   D8H 异常
异常信息字：01 数据非法 / 02 无请求数据项 / 04 密码错
            / 08 速率不能更改 / 10 远程控制失败 / 20 升级包错误
```

**字节序**：电压/电流/剩余电流/整定值等**数值量**多字节低字节在前；
日期、时间、密码、操作者、自检 DDhhmm 等**分量型**按书写顺序传输。

## 八、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 打开串口失败（拒绝访问） | 端口被上位机/串口助手占用；虚拟串口对两端不能同时被同一程序打开 |
| 上位机"无应答(超时)" | 设备未开始监听、端口不是同一对、地址不符、随机丢帧开启 |
| 上位机"校验和错误" | 虚拟设备开启了"破坏校验码"随机行为；或手工改帧后未重算 CS |
| 数据为 0 / 波形平直 | "设备运行"未勾选（停电）、已分闸（无负荷电流）、或注入了停电工况 |
| 注入漏电不跳闸 | 已处于分闸状态；或控制字 4 的 bit1-0 = 00（不跳闸不告警）；或保护逻辑总开关被关闭 |
| 注入过载迟迟不跳 | t1 为长延时（默认 120s），可把"保护时间加速"调大（如 60 倍） |
| 中文显示为方框 | 系统缺少微软雅黑等字体；程序会自动回退到其它中文字体 |
